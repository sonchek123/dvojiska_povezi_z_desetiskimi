# Poveži števila – Interaktivna vaja za dvojiški sistem

Ta spletna aplikacija omogoča učencem vajo pretvarjanja dvojiških števil v desetiški sistem na igriv in vizualen način.

## Kaj počne?

- Učenci vlečejo dvojiška števila iz levega stolpca in jih spustijo na ustrezna desetiška števila v desnem stolpcu.
- Če je povezava pravilna, se par označi kot rešen.
- Če je napačna, se povezava začasno obarva rdeče.
- Kartice ostajajo poravnane in pregledne.

## Funkcionalnosti

- Izbira števila parov: 5, 10 ali 15
- Izbira obsega števil: 1–15, 1–31 ali 1–63
- Dvojiška števila so prikazana s 5 biti (npr. `00110`)
- Interaktivno povleci–spusti delovanje
- Prijazno do GitHub Pages

## Namestitev in uporaba

1. Naloži `index.html` v korensko mapo GitHub repozitorija.
2. V nastavitvah (Settings > Pages) omogoči GitHub Pages iz veje `main`.
3. Odpri povezavo do objavljene strani in začni z uporabo.

## Namenjeno za

- Učence 4.–6. razreda osnovne šole
- Računalniške dneve ali učne ure informatike
- Vadbo binarnega sistema brez prijave ali računa

## Avtor

Projekt pripravljen kot del sklopa aktivnosti o dvojiških številih in interaktivnem učenju. Pripravljeno kot test z ChatGPT.
